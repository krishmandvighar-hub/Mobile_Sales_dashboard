# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview
This project is an interactive **Mobile Sales Dashboard** developed in **Power BI** to analyze mobile phone sales performance across different brands, cities, models, and payment methods. The dashboard provides meaningful insights through dynamic visualizations and KPIs, enabling better business decision-making.

## 🎯 Objective
The goal of this dashboard is to monitor sales performance, identify top-selling mobile brands and models, analyze customer purchasing trends, and evaluate revenue growth using interactive reports.

## 📊 Dashboard Features
- Executive Summary
- Sales Performance Analysis
- Brand-wise Sales Comparison
- Model-wise Sales Analysis
- Monthly Sales Trend
- City-wise Sales Performance
- Payment Method Distribution
- Customer Ratings Analysis
- Interactive Filters and Slicers

## 📈 Key KPIs
- 📦 Total Quantity Sold
- 💰 Total Sales
- 📊 Average Sales
- ⭐ Average Customer Rating
- 🏆 Top Selling Brand
- 📱 Top Selling Mobile Model
